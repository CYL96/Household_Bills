# README Web 与 Android App 界面截图

## 背景与目标

项目首页需要展示两端界面，让读者在部署前了解 Web 和 Android 客户端的实际样子。最初添加的是手绘 SVG 示意图，用户要求改为真实截图。

## 实际变更

- 在根 `README.md` 的功能介绍后保留「界面截图」章节，正文明确说明截图来自实际运行的应用、使用临时演示账本，金额和记录均为示例数据。
- 新增 `docs/images/web-overview.png`：桌面浏览器 1440 × 900 视口、1.5 倍像素密度导出的总览页实际截图（2160 × 1350）。
- 补充 `docs/images/web-transactions.png`（2160 × 1500）：真实流水明细页，展示月份筛选、分类、金额、账户、备注和成员。
- 补充 `docs/images/web-statistics.png`（2160 × 1650）：真实统计报表页，展示支出分类环形图、分类金额、占比和笔数。
- 新增 Android 三张真实截图：`android-overview.png`、`android-transactions.png` 和 `android-statistics.png`，均为 1080 × 2400，分别对应总览、流水明细和统计报表；原 `android-app.png` 重命名为 `android-overview.png`。
- README 的 Android App 部分用 Markdown 表格并排展示三张竖屏截图；Web 与 Android 均使用标准 Markdown 图片语法，不依赖原始 HTML 标签或 `width` 属性。
- 删除上一版手绘的 `docs/images/web-overview.svg` 与 `docs/images/android-app.svg`，不保留重复内容。

## 截图环境

- 使用仓库外的临时 PostgreSQL 集群中单独创建的演示数据库，临时后端仅监听 `127.0.0.1:18993`，未连接本机生产数据库或生产服务。
- 通过 API 创建演示家庭数据：3 个资金账户、1 位成员，以及 2026 年 10 月的演示收支和转账；截图展示实际查询和计算结果。
- Web 截图由 Headless Chromium 打开临时后端页面，实际登录后在月份选择器中选择 2026 年 10 月，再截取页面。
- Android 截图在独立 AVD（Android 35 x86_64）中安装仓库现有的 debug APK，连接同一临时后端，实际登录并通过触摸选择 2026 年 10 月后用 `adb exec-out screencap -p` 原样保存；未使用网页截图代替。三张截图分别停留在总览、流水明细和统计报表，选择月份后确认无下拉浮层、加载遮罩或弹窗再截屏。
- 补充明细和统计截图时重建独立演示数据库；浏览器实际打开 `/transactions?month=2026-10` 与 `/statistics/reports`，在报表月份选择器中选择 2026 年 10 月，等待记录和图表加载后截图，未重绘页面或篡改响应。
- 截图不包含密码、令牌或真实家庭账本数据；演示数据与临时服务在验证结束后清理。

## 验证结果

- 检查 README 中的六条图片引用均指向存在的 PNG 文件，无遗留 SVG 引用。
- 读取 PNG 确认格式与尺寸：Web 总览为 2160 × 1350、流水明细为 2160 × 1500、统计报表为 2160 × 1650；Android 三张均为 1080 × 2400。
- 实际查看六张截图，界面文字、金额、列表、图表与月份显示正常，未出现加载中或错误状态。
- Android 流水明细显示“2026年10月流水”“共 40 笔记录”；统计报表显示支出 ¥5,153.00、收入 ¥15,956.80，分类金额与 Web 报表一致。
- Web 截图与 Android 截图显示相同的 2026 年 10 月演示数据：收入 ¥15,956.80、支出 ¥5,153.00、结余 ¥10,803.80、家庭总余额 ¥62,990.00。
- 用户反馈 App 图片未显示后，已确认远端 README 与 Android PNG 均已发布、图片 URL 可访问。原 App 引用单独使用 HTML `<img>`；在禁用原始 HTML 的 Markdown 渲染模式中，旧引用输出为文本而非图片，标准 Markdown 引用则正常生成图片元素。尚未确认用户具体使用的阅读器，HTML 兼容性为本次修复针对的原因。
- 使用禁用 HTML 块和内联 HTML 的 Markdown 解析模式生成 README，再用 Chromium 实际加载预览：六张图片均加载完成，Android 三张并排渲染为约 291 像素宽，确认表格布局与图片可见。未修改或重新绘制图片内容。
- 未验证 GitHub 远端页面上的实际渲染；验证范围为本地图片文件与 README 引用。
- 未运行前后端构建或业务测试：本次只修改文档并新增截图，未改动运行代码。Android 截图使用已有 debug APK。
