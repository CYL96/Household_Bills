# README Web 与 Android App 界面截图

## 背景与目标

项目首页需要展示两端界面，让读者在部署前了解 Web 和 Android 客户端的实际样子。最初添加的是手绘 SVG 示意图，用户要求改为真实截图。

## 实际变更

- 在根 `README.md` 的功能介绍后保留「界面截图」章节，正文明确说明截图来自实际运行的应用、使用临时演示账本，金额和记录均为示例数据。
- 新增 `docs/images/web-overview.png`：桌面浏览器 1440 × 900 视口、1.5 倍像素密度导出的总览页实际截图（2160 × 1350）。
- 新增 `docs/images/android-app.png`：Android 模拟器真实屏幕截图（1080 × 2400），显示手机上的总览、统计卡片、走势图和底部导航。
- Android 图片在 README 中使用 `width="320"` 控制展示宽度，避免竖屏原图占满页面。
- 删除上一版手绘的 `docs/images/web-overview.svg` 与 `docs/images/android-app.svg`，不保留重复内容。

## 截图环境

- 使用仓库外的临时 PostgreSQL 集群中单独创建的演示数据库，临时后端仅监听 `127.0.0.1:18993`，未连接本机生产数据库或生产服务。
- 通过 API 创建演示家庭数据：3 个资金账户、1 位成员、2026 年 10 月的 42 笔收支和 1 笔转账；截图展示该月的真实计算结果。
- Web 截图由 Headless Chromium 打开临时后端页面，实际登录后在月份选择器中选择 2026 年 10 月，再截取页面。
- Android 截图在独立 AVD（Android 35 x86_64）中安装仓库现有的 debug APK，连接同一临时后端，实际登录并通过触摸选择 2026 年 10 月后用 `adb exec-out screencap -p` 原样保存；未使用网页截图代替。
- 截图不包含密码、令牌或真实家庭账本数据；演示数据与临时服务在验证结束后清理。

## 验证结果

- 检查 README 中的两条图片引用均指向存在的 PNG 文件，无遗留 SVG 引用。
- 读取两张 PNG 确认格式与尺寸：Web 为 2160 × 1350，Android 为 1080 × 2400。
- 实际查看两张截图，界面文字、金额、走势图与月份显示正常，未出现加载中或错误状态。
- Web 截图与 Android 截图显示相同的 2026 年 10 月演示数据：收入 ¥15,956.80、支出 ¥5,153.00、结余 ¥10,803.80、家庭总余额 ¥62,990.00。
- 未验证 GitHub 远端页面上的实际渲染；验证范围为本地图片文件与 README 引用。
- 未运行前后端构建或业务测试：本次只修改文档并新增截图，未改动运行代码。Android 截图使用已有 debug APK。
