# README Web 与 Android App 界面截图

## 背景与目标

项目首页需要展示两端界面，让读者在部署前了解 Web 和 Android 客户端的实际样子。最初添加的是手绘 SVG 示意图，用户要求改为真实截图，并进一步要求减少页面高度：Web 与 Android 各合并为一张图片，只保留界面重点区域。

## 实际变更

- 在根 `README.md` 的功能介绍后保留「界面截图」章节，正文说明截图来自实际运行的应用、使用临时演示账本，金额和记录均为示例数据。
- 新增 `docs/images/web-pages.png`（2160 × 3265）：从 Web 总览、流水明细、统计报表三张实际截图分别裁取重点区域后，自上而下拼接为一张；总览保留统计卡片和完整走势图，明细保留筛选和流水表，报表保留环形图和分类金额列表。
- 新增 `docs/images/android-app.png`（3272 × 2400）：由 Android 总览、流水明细、统计报表三张真实模拟器截图横向拼接为一张。
- README 的 Web 端和 Android App 各使用一张标准 Markdown 图片，不依赖 HTML；拼接与裁剪只做等比例排列和区域截取，不修改截图内容。
- 各页面单独截图不保留，避免仓库和页面重复占用空间。
- 删除上一版手绘的 `docs/images/web-overview.svg` 与 `docs/images/android-app.svg`，不保留重复内容。

## 截图环境

- 使用仓库外的临时 PostgreSQL 集群中单独创建的演示数据库，临时后端仅监听 `127.0.0.1:18993`，未连接本机生产数据库或生产服务。
- 通过 API 创建演示家庭数据：3 个资金账户、1 位成员，以及 2026 年 10 月的演示收支和转账；截图展示实际查询和计算结果。
- Web 截图由 Headless Chromium 打开临时后端页面，实际登录后在月份选择器中选择 2026 年 10 月；分别截取 `/`、`/transactions?month=2026-10` 与 `/statistics/reports`，再用浏览器按原始像素裁剪并拼接。
- Android 截图在独立 AVD（Android 35 x86_64）中安装仓库现有的 debug APK，连接同一临时后端，实际登录并通过触摸选择 2026 年 10 月后用 `adb exec-out screencap -p` 原样保存；未使用网页截图代替。分别截取总览、流水明细和统计报表，选择月份后确认无下拉浮层、加载遮罩或弹窗再截屏，再横向拼接成一张 PNG。
- 截图不包含密码、令牌或真实家庭账本数据；演示数据与临时服务在验证结束后清理。

## 验证结果

- 检查 README 中的两条图片引用均指向存在的 PNG 文件，无遗留 SVG 或已删除页面的引用。
- 读取 PNG 确认格式与尺寸：`web-pages.png` 为 2160 × 3265，`android-app.png` 为 3272 × 2400。
- 实际查看两张图片：Web 拼接图的走势图完整，明细停在完整行，报表环形图与分类金额正常；Android 拼接图依次显示总览、流水明细和统计报表。
- Android 流水明细为“2026年10月流水”“共 40 笔记录”，统计报表支出 ¥5,153.00、收入 ¥15,956.80；Web 与 Android 均显示 2026 年 10 月演示数据：收入 ¥15,956.80、支出 ¥5,153.00、结余 ¥10,803.80、家庭总余额 ¥62,990.00。
- 使用禁用 HTML 块和内联 HTML 的 Markdown 解析模式生成 README，再用 Chromium 实际加载预览：两张图片均加载完成并按页面宽度缩放显示，确认单图布局与图片可见。
- 未验证 GitHub 远端页面上的实际渲染；验证范围为本地图片文件与 README 引用。
- 未运行前后端构建或业务测试：本次只修改文档并处理截图，未改动运行代码。Android 截图使用已有 debug APK。
