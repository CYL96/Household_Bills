# 分类图标库扩充至 1000 个

## 背景与目标

分类图标选择器原有 300 个可选图标，本次扩充至准确 1000 个，继续支持按中文分组选择，并保留用户已经保存的图标配置。

## 实际变更

- 在 `frontend/src/utils/categoryIcons.ts` 中新增 700 个 Lucide 图标，沿用现有具名导入与 `lucide-<名称>` 稳定标识规则。
- 保留原有 300 个图标的 ID、中文标签、分组和组件；原有默认图标、内置分类映射及回退逻辑不变。
- 新增选项均提供中文标签，继续使用现有 13 个分组，没有新增依赖或修改图标库版本。
- 目录仍由分类编辑器、分类设置和记账入口共同使用，白名单与 `CategoryIconId` 类型随目录自动扩展，无需维护第二份列表。

## 验证与结果

- 临时数据校验通过：新增 700 条均来自当前已安装 Lucide 版本的真实导出，按实际模块排除别名重复；全部选项使用有效分组，1000 个中文标签无重复。
- 执行临时 Node/Vite SSR 冒烟脚本，通过真实目录与 Vue 服务端渲染器逐一渲染全部 1000 个组件：生成 1000 份不同且包含 SVG 图形节点的输出，ID 与组件引用均无重复，每个选项通过白名单并由 `categoryIcon()` 正确解析。
- 与修改前目录快照逐条比较，原有 300 个图标的 ID、标签、分组和组件引用完全一致，13 个分组保持不变；内置名称映射与未知名称回退检查通过。
- 使用内存 localStorage 和隔离的临时身份调用实际 `saveCategoryEntries()` / `readCategoryEntries()`：1000 个图标保存后全部正确恢复，不访问真实用户存储。
- 执行 `frontend/` 下的 `npm run build`：`vue-tsc --noEmit` 与 Vite 生产构建均通过。构建仍提示部分 chunk 超过 500 kB，其中记账页面 chunk 为 621.35 kB（gzip 136.80 kB）；本次没有调整分包策略或抑制警告。
- 验证用目录快照和冒烟脚本已删除，不新增永久测试框架。
- 未运行后端测试：本次未修改后端、API 或数据库。
- 未进行浏览器页面外观及交互验证；SVG 渲染验证不代表页面视觉验收。

## 兼容性与迁移

- 无 API、数据库或本地存储结构变更，无需迁移。
- 已保存的全部原有图标 ID 继续有效；未改变默认图标与历史分类显示方式。
- 继续使用现有 Element Plus 与 Lucide 依赖及许可文件，不引入外部图标请求。
- 新图标增加了随应用打包的资源量；本次仅扩充目录，不额外引入搜索、懒加载或其他交互改动。
