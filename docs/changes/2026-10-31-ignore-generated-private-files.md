# 提交前排除生成文件与私人账单附件

## 背景与目标

提交并推送当前积累的功能变更前，区分源码、测试与构建产物、本机配置、私人账单附件，避免将无须版本管理的文件加入仓库或 Docker 构建上下文。

## 实际变更

- 根 `.gitignore` 补充 `*.apk`、`*.aab`，防止复制到构建目录之外的 Android 安装包误入版本库。
- 根 `.gitignore` 与 `.dockerignore` 排除根目录 `/content_[0-9]*`，覆盖本次一次性私人账单导入附件；不删除本地原件，不影响 `content_schema.json` 等非数字编号文件。
- 保留现有环境文件、前端依赖与构建目录、Go 二进制、Android 缓存、构建目录、发布目录和签名密钥忽略规则；保留 Android 工程内的本机配置与 IDE 忽略规则。
- Dockerfile 只使用 `frontend/` 和 `backend/`；`.dockerignore` 将零散 Android 产物规则合并为排除整个 `/android/`，并排除已有 Git 忽略规则对应的 `/test/` 本地手工测试目录。APK 发布目录仍通过运行时只读挂载提供，不依赖 Docker 构建上下文。
- Android 源码、资源、测试、工程配置以及 Gradle Wrapper 的脚本、JAR 和 properties 文件均保留提交；未添加宽泛的 `*.jar` 忽略规则。

## 实际验证

- `git check-ignore -v`：18 个应排除路径全部命中规则，覆盖真实私人附件及构建包、缓存、发布清单、本机配置、密钥、环境文件、前端产物与手工测试目录等边界。
- 反向检查 13 个应保留路径：`.env.example`、Gradle Wrapper、Android 构建配置/清单/测试、前后端源码、文档和非数字编号 `content_` 文件均未被忽略。
- 暂存前 `git diff --check` 通过；暂存全部既有改动后，`git diff --cached --check` 报告 Windows Wrapper 的 CRLF 行尾及既有账单导入记录末尾空行。读取字节确认 `gradlew.bat` 为 94 行 CRLF、无单独 LF；保留官方脚本格式及既有文档内容，不将此项记录为全量检查通过。
- 暂存区边界检查通过：72 个文件中没有私人附件、构建产物、签名密钥或本机 SDK/签名配置，Gradle Wrapper、环境配置示例和 Android 测试均包含在内。
- 未运行应用构建、业务测试或 Docker 镜像构建；本次新增修改仅涉及忽略规则，不将既有功能记录中的验证算作本次执行结果。

## 兼容性与迁移

无需数据库迁移或运行配置变更。忽略规则不删除任何本地数据，不移除既有已跟踪文件；原始私人附件保留在本机，不随提交上传。
