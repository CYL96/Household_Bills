# 流水明细左滑显示编辑和删除

## 背景与目标

手机流水卡片原先在底部常驻编辑、删除按钮。本次调整为左滑条目后显示操作，减少常态展示中的按钮干扰；滑动本身不修改或删除账目。

## 实际变更

- 修改 `frontend/src/components/TransactionList.vue` 的移动端分支（宽度不超过 760px），将编辑、删除移到卡片右侧隐藏操作区，保留分类、金额、账户、备注、类型及归属成员信息。桌面表格操作列不变。
- 使用 Pointer Events 实现跟手位移；横向移动达到 8px 后识别手势，纵向意图交还原生页面滚动，保留 `touch-action: pan-y`。操作区宽 152px，超过一半时吸附展开，否则回弹；右滑可收起。
- 同时最多展开一条。点击卡片外部、点击已展开的卡片表面、按 Escape、切换列表数据或移动/桌面断点时收起；取消手势时清理拖动状态和指针捕获，卸载时移除监听。
- 编辑、删除入口先收起操作区，再调用原有编辑弹窗或删除确认流程；保留编辑禁用条件、删除中的禁用及加载图标、确认文案、防重复和数据刷新行为。
- 卡片支持键盘聚焦，Enter、空格或左方向键展开，右方向键或 Escape 收起；隐藏操作区使用 `inert` 和 `aria-hidden`，避免不可见按钮进入焦点顺序。操作按钮保留逐条中文标签及至少 44px 的触控尺寸。
- 保留响应式卡片布局，并为减少动态效果偏好关闭位移动画。流水页与报表下钻复用同一组件，同步生效。

## 验证与结果

- 在 `frontend/` 执行 `npm run build`：TypeScript 检查和 Vite 生产构建通过；Vite 仍提示部分产物超过 500 kB，无构建错误。
- 通过 Vite preview 加载实际生产构建，使用独立 Chromium 及临时 API 响应夹具提供认证、家庭分类、账户与 12 笔流水；未连接或写入现有数据库。验证浏览器配置了可用中文字体，并截屏检查了展开后的操作区。
- 手机视口 390×844，通过 Chromium 原生触控输入验证：默认隐藏且操作区不可聚焦、关闭态右滑不会误开、短距离左滑回弹、取消触控回弹、左滑展开、另一条展开时关闭上一条、右滑收起、点击外部收起。以上操作未发起写请求。
- 验证原生纵向触控能滚动页面，且不会误展开操作；验证键盘左方向键展开、Tab 可进入对应编辑按钮、Escape 收起。
- 点击编辑后打开包含对应流水备注的原编辑弹窗，操作区同步收起。
- 分别验证普通收支与账户转账的删除入口：原确认框显示对应分类、金额，以及转账的两端账户和余额重算提示；点击取消后没有写请求。
- 切换到 1366×900 桌面视口，12 笔流水仍显示原表格和 24 个编辑/删除按钮；切回手机后没有遗留展开状态。
- 实际打开 `/statistics/reports`，从一级分类进入二级分类再进入流水明细；验证共享操作区能展开。账户夹具为空时编辑按钮禁用，删除仍可显示对应确认框，取消后无写请求。
- 未执行后端测试、真实登录/数据库持久化端到端验证、删除确认后的实际删除或 Android 设备手势验证；本次未修改后端及持久化逻辑。

## 兼容性与迁移

不新增依赖，不改变 API、数据库、组件 props 或事件契约，无数据迁移。Android 外壳加载网页，同样使用此移动端列表实现；本次没有修改或重新构建 APK。
