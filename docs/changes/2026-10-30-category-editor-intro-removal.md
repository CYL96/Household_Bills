# 删除分类编辑页的重复标题与说明

## 背景与目标

分类编辑页顶部导航已经显示当前操作标题，表单内又重复显示标题及草稿保存说明。根据截图标注，删除表单内的这块介绍区域。

## 实际变更

- 删除 `frontend/src/components/CategorySettingsDialog.vue` 中编辑表单内的重复标题和“修改只会更新当前草稿……”说明。
- 删除只供该介绍区域使用的样式。
- 保留顶部导航标题、返回按钮、错误提示、分类名称输入、图标选择及底部操作按钮。
- 新建一级分类、新建子分类和修改分类共用的编辑页均不再显示该重复介绍区域。

## 验证与结果

- 执行 `frontend/` 下的 `npm run build`：TypeScript 类型检查及 Vite 生产构建通过。
- 构建仍有部分 chunk 超过 500 kB 的体积警告，本次未调整分包策略。
- 未进行浏览器视觉及交互验证；构建通过不代表页面外观已经验收。
- 未运行后端测试，本次不涉及后端或数据行为变更。

## 兼容性

仅删除界面介绍内容及对应样式，不改变分类数据、保存流程、API 或本地存储结构，无需迁移。
