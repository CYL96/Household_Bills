# 总览页精简介绍、快速记账与分类图

## 背景与目标

按界面截图绿色框标注，删除总览页的“家庭财务一览”小标题、家庭共同维护账户及流水的说明文字，以及整块“快速记账”卡片。保留月份标题、月份选择、统计内容和原有记账能力。

后续按第二张截图标注，继续移除总览页整块“支出分类”卡片（标题、总额、分类层级切换、环形图与图例），保留“家庭总余额”和“每日收支走势”。

## 实际变更

- `frontend/src/views/DashboardView.vue` 删除上述三个区域，并移除快速卡片专用图标导入及桌面、移动端样式。
- `frontend/src/styles/main.css` 删除不再使用的说明文字样式，保留其他页面和空态共用样式。
- 保留手机端右下角“+”及桌面端“记一笔”入口；记账弹窗仍提供支出、收入、转账切换。
- `README.md` 同步记账入口说明，不再描述已删除的三个快捷按钮。
- 后续删除总览支出分类卡片及其专用状态、计算、分类配置依赖、图表选项、无障碍描述和样式；删除不再有调用方的 `frontend/src/utils/categoryStatistics.ts`。
- 移除原双图网格包装，走势图直接占满内容宽度；加载骨架同步由两个图表占位改为一个。
- `README.md` 同步移除总览分类图和层级切换说明；原分类图层级切换记录标注为历史功能。独立统计页及后端汇总接口保持不变。
