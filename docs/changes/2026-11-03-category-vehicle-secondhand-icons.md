# 交通、3D 打印机与二手分类图标

## 背景与目标

为分类图标选择器提供明确的汽车、摩托车、自行车、3D 打印机及二手交易选项，沿用现有图标库和分组，避免重复图形。

## 实际变更

- 修改 `frontend/src/utils/categoryIcons.ts`，沿用现有 `@lucide/vue` 依赖。
- 「交通」分组中的汽车图标显示名由「交通」调整为「汽车」；保留已有「摩托车」「自行车」选项，不重复添加相同图形。
- 「购物」分组中的「三维打印」显示名调整为「3D打印机」。
- 「购物」分组新增四个选项：

| 显示名 | 图标 ID | 图形 |
| --- | --- | --- |
| 二手出售 | `lucide-badge-dollar-sign` | 金额徽章 |
| 二手淘货 | `lucide-package-search` | 包裹与放大镜 |
| 二手拍卖 | `lucide-gavel` | 拍卖锤 |
| 以旧换新 | `lucide-refresh-cw` | 循环箭头 |

图标总数由 500 增至 504，「购物」分组由 48 增至 52。选择器及图标白名单均从现有目录派生，无需修改消费者。

- `frontend/` 执行 `npm run build`：TypeScript 检查及 Vite 生产构建通过。构建提示部分产物超过 500 kB；本次未修改分包配置。

- 检查目标选项实际渲染 SVG，并截图观察购物图标网格与新增二手图形。验证环境缺少中文字体，截图中文呈方框；DOM 中显示名、选择提示和提交数据核对通过。
