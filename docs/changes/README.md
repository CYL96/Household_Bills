# 任务与需求记录

本目录按任务或需求保存变更记录，不将所有更新累积到根目录 `README.md` 或单个日志文件中。

## 记录约定

- 文件命名为 `YYYY-MM-DD-topic.md`，日期使用记录创建日期，主题使用简短、有意义的小写英文与连字符，例如 `2026-10-30-documentation-records.md`。
- 一个任务或需求对应一个文件；同一任务的后续调整更新原文件，独立需求另建文件。
- 使用中文，说明背景与目标、实际变更、验证结果，以及适用时的兼容性或迁移注意事项。
- 验证只记录实际执行的检查及其结果；未执行的检查明确标注，不将计划写成完成结果。
- 不记录密码、令牌、真实连接凭据等敏感信息。
- 根目录 `README.md` 保留项目概览、安装运行、配置和必要使用说明；只有这些内容确实变化时才更新，不追加逐次任务记录。

按文件名浏览本目录即可，无需每次在根目录 README 或本文件追加记录索引。仓库级约束见 [AGENTS.md](../../AGENTS.md)。
