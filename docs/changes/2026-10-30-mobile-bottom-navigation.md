# 手机底部导航切换

## 背景与目标

将手机上的「总览、明细、统计」移至底部直接切换，保留桌面侧栏和其他页面入口。

## 实际变更

- `frontend/src/layouts/AppLayout.vue`：在不超过 760px 的视口显示固定底部导航，提供「总览」「明细」「统计」三个图标与文字入口；统计直接进入现有报表页。当前项随路由高亮，并设置 `aria-current="page"`，明细与统计覆盖对应子路径。
- `frontend/src/components/AppNav.vue`：区分侧栏与抽屉；手机抽屉不重复展示上述主要导航，仍保留资金账户、家庭成员以及原有个人设置和退出登录操作。761–960px 的抽屉和桌面侧栏保持原导航。
- 通过布局变量统一底栏高度，为页面末尾预留空间，并将手机「记一笔」浮动按钮上移到导航上方。底栏包含安全区内边距，层级低于抽屉和对话框。

## 验证结果

- `frontend/` 执行 `npm run build`：`vue-tsc --noEmit` 和 Vite 构建通过；构建提示部分压缩后产物超过 500 kB，没有构建错误。
- 使用 Chromium 打开实际构建页面并登录，在 390×844 手机视口实测三个底栏入口：总览回到 `/`、明细进入 `/transactions`、统计进入 `/statistics/reports`，当前项均正确高亮；截图确认底栏显示正常。
- 390×844 下底栏占据纵向 786–844px，浮动按钮底边为 770px，未重叠。明细滚动到底后，最后可见面板底边约为 670px，位于浮动按钮顶边 722px 和底栏上方。
- 手机抽屉仅保留资金账户、家庭成员两项页面入口，点击资金账户成功进入该页面；抽屉遮罩层级高于底栏。点击「记一笔」可打开实际记账弹窗，弹窗层级高于底栏，随后关闭，未保存或修改账目。
- 1280×900 桌面视口：底栏隐藏，原侧栏导航保留；800×900 平板视口：底栏隐藏，抽屉仍提供总览、流水明细和统计等原导航。
- 320px、760px 宽度显示底栏，761px 隐藏底栏；三个宽度均未出现横向溢出。验证期间浏览器未记录页面运行错误。
- 未运行后端测试：本次仅调整前端导航和布局，未修改 API 或数据库。
- 未进行 iOS/Android 真机验证，也未模拟非零安全区；当前页面未启用 `viewport-fit=cover`，沿用既有视口配置，不额外扩展顶部安全区行为。

## 兼容性与迁移

无新增依赖、无后端接口变化、无数据库迁移。部署时重新构建前端产物；屏幕宽于 760px 时保留原有导航方式。
