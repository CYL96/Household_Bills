# 登录页指定文案删除

## 背景与目标

按截图红框删除登录页宣传内容及辅助说明，保留品牌、欢迎标题和登录表单。

## 实际变更

- 在 `frontend/src/views/LoginView.vue` 删除左侧宣传标题、介绍、三条功能说明和底部短句。
- 删除登录卡片中的“家庭财务空间”、登录说明、联系管理员创建账号提示，以及成员可见和人民币说明。
- 清理上述元素的专用样式；保留桌面和移动端品牌、背景装饰、响应式布局、连接失败提示及登录表单逻辑。

## 验证结果

- `cd frontend && npm run build`：通过 TypeScript 检查及 Vite 生产构建；构建输出包含部分分块超过 500 kB 的提示。
- 通过临时 Node 命令使用 Vite 加载真实 `LoginView.vue`，结合 Vue SSR、Vue Router 和 Element Plus 渲染：确认品牌、欢迎标题、用户名、密码、登录按钮仍存在，红框内文案均不再输出，并检查输入框自动填充属性与提交按钮类型。
- 首次 SSR 验证断言通过，但关闭临时 Vite 服务时依赖扫描报错；在临时命令中禁用不需要的依赖自动扫描后重新运行，通过且正常退出。未修改项目 Vite 配置，未留下临时脚本。
- 按仓库要求未进行浏览器外观或交互验收；SSR 验证不代表视觉效果或实际登录请求验证。未运行后端测试，本次不涉及后端。

## 兼容性

仅删除页面静态内容及失效样式，不变更 API、认证流程或数据库，无需迁移。
