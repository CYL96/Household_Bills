# 流水明细列表头部精简

## 背景与目标

按界面截图中的红框，删除流水列表上方的月份流水标题和右侧“账”装饰徽标，避免重复展示月份信息。

## 实际变更

- 在 `frontend/src/views/TransactionsView.vue` 删除动态月份流水标题与“账”徽标。
- 保留加载提示、记录数量、流水列表、月份筛选、收支合计和记账入口。
- 移除仅供标题使用的计算属性、日期格式化导入和废弃样式，将头部简化为记录数量段落，保留移动端间距规则。

## 验证结果

- 执行 `frontend/` 下的 `npm run build`，TypeScript 检查与 Vite 构建通过；构建提示部分产物超过 500 kB。
- 使用本地运行中的服务及真实登录会话，在 Chromium 打开 `/transactions`，分别检查 491×811 和 1440×1000 视口并截图：列表显示“共 33 笔记录”，标题和徽标节点均不存在，页面没有横向溢出，流水记录与合计正常显示。
- 浏览器环境缺少中文字体，截图中的中文显示为缺字方框；中文文案通过 DOM 文本核验，截图用于检查布局，不作为中文字体效果证明。
