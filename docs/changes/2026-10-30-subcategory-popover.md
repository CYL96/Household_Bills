# 子分类选择浮层优化

## 背景与目标

参考移动端示意图，点击包含子分类的一级分类时，子分类应在所点分类附近展开，而不是固定出现在屏幕顶部。保留当前分类数据、记账选择及关闭行为。

## 实际变更

- 修改 `frontend/src/components/TransactionDialog.vue`，沿用 Element Plus 对话框的遮罩、焦点约束和关闭机制，将子分类面板改为锚定父分类按钮的圆角浮层。
- 面板增加指向父分类的小尖角，优先向下展开；下方空间不足且上方空间更大时向上展开，尖角随之切换方向。
- 宽度参考分类网格，最大 440px，左右保留至少 12px 视口边距；子分类采用自适应图标网格，长名称不撑破布局。
- 面板按可用空间限高，内容区域内部滚动，返回、父类标题和关闭按钮保持可见；继续提供父类本级「不细分」入口。
- 打开期间随窗口尺寸、可视视口变化、分类区域尺寸和滚动更新位置；关闭或组件卸载时清理监听、观察器及待执行定位任务。
- 子分类选中后仍更新原有分类字段、关闭面板并将焦点返回父分类按钮；Esc、遮罩及返回按钮的关闭语义不变。

## 验证与结果

- 在 `frontend/` 执行 `npm run build`：通过 TypeScript 检查和 Vite 生产构建。Vite 提示部分产物超过 500kB；本任务不涉及打包拆分。
- 使用仓库外临时脚本，在 jsdom 中挂载实际 `TransactionDialog`、Vue Router 和 Element Plus，实际派发点击、键盘、resize 和 scroll 事件；为无布局的 DOM 环境提供模拟矩形尺寸。以下检查通过：
  - 默认在父分类下方定位，左侧不越界，停用子分类不展示。
  - 选择子分类后关闭面板、更新父分类下的子类标签并回焦。
  - 可以直接选择父分类本级，清除此前选中的子类标签。
  - 父分类靠近视口底部时面板向上展开。
  - Esc 只关闭子分类面板，保留记账窗口并回焦；点击遮罩也可以关闭。
  - 模拟 320px 窄屏和超长内容时限制面板宽高，桌面调整尺寸后宽度不超过 440px。
  - 滚动后更新锚点位置；打开面板时卸载组件没有运行时错误。
- 未使用浏览器，未验证真实手机的视觉效果、软键盘和触摸滚动观感；上述模拟尺寸检查不等同于真实页面布局验证。
- 未运行后端测试：本次不涉及后端逻辑。未引入前端测试框架或永久测试文件，临时验证脚本不入库。

## 兼容性与迁移

无 API、数据库、分类存储格式或依赖变更，不需要迁移。根目录使用说明中原有的“选择子分类或直接记在一级分类下”仍然适用。
