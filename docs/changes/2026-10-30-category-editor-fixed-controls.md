# 分类编辑页固定名称与图标分组区域

## 背景与目标

分类编辑页的名称输入、图标分组及当前选择原本与图标列表一起滚动。根据截图要求，将这些控件保留在可视区域上方，仅由下方图标网格承担常规滚动，保留顶部返回栏和底部操作按钮。

## 实际变更

- 调整 `frontend/src/components/CategoryEditor.vue` 的全屏 flex 高度链：移除根节点 `min-height: 100%`，改为可伸缩的剩余空间布局。
- 名称输入区、图标标题、分组按钮、当前选择和操作按钮不参与收缩；图标区域及图标网格允许收缩，网格沿用独立纵向滚动。
- 图标网格按起始位置排列，避免图标较少时卡片被剩余高度拉长。
- 图标区域从 `fieldset/legend` 改为 `div role="group"` 配合 `aria-labelledby`，保留可访问的分组名称，避免将原生 fieldset 作为嵌套 flex 高度分配容器。
- 删除 `frontend/src/components/CategorySettingsDialog.vue` 中编辑面板的常驻滚动条预留空间。面板保留纵向溢出兜底，极矮视口或输入提示使固定控件本身放不下时，仍允许访问全部控件。
- 新的剩余高度分配规则仅适用于全屏编辑模式；非全屏模式继续使用原有网格最大高度。

## 验证与结果

- 临时 Node/Vite SSR 冒烟验证通过：实际渲染全屏及非全屏分类编辑器，均包含名称输入、有可访问名称的图标区域、13 个分组按钮、默认通用组的 70 个单选图标、当前选择提示及底部操作按钮。
- 冒烟脚本最初按固定 CSS class 顺序匹配选中按钮而失败，修正为按 class 集合匹配后两个模式均通过；未因此修改业务逻辑。
- 执行 `frontend/` 下的 `npm run build`，TypeScript 类型检查和 Vite 生产构建通过。构建仍提示部分 chunk 超过 500 kB，本次未调整分包策略。
- 临时冒烟脚本已删除。
- 未进行浏览器或移动设备视觉、滚动及软键盘验证；SSR 验证不能证明实际像素布局或滚动效果。
- 未运行后端测试，本次不涉及后端。

## 兼容性

不改变分类名称校验、图标目录、选择事件、保存流程或本地存储格式，无需数据迁移。极端低高度视口仍保留外层溢出兜底，而非裁掉名称或操作按钮。
