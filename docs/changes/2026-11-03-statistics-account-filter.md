# 统计报表账户与用户筛选

## 背景与目标

统计主页增加账户和记账归属用户筛选，两者在电脑和手机上均保持同行；进入二级分类和流水明细后沿用主页选择，不在下级页面重复提供筛选。

## 实际变更

- `frontend/src/views/ReportsView.vue`：在报表根层的月份选择器旁增加可清空的账户选择器，默认“全部账户”，复用已有账户列表。
- 通过现有流水接口的 `account` 参数加载所选账户数据。收支总额、环形图、大小分类和明细共用这份数据，转账仍不计入收支。
- 二级分类和明细隐藏账户筛选，返回根层保留选择；切换月份或收入/支出不清空账户。清空选择后恢复全部账户。
- 月份与账户变化共用监听器，重置下钻并重新加载；保留原有序号机制，避免旧请求覆盖新结果。
- 空状态改为描述当前筛选条件，避免把某账户无记录误述为整个月无记录。
- 桌面月份、账户、用户选择器宽度分别为 152px、180px、160px；修正 Element 日期控件根节点没有 scoped 属性导致原宽度规则失效的问题，使用局部 `:deep` 选择器。640px 及以下月份单独全宽，账户与用户等宽并排显示。
- `README.md` 的功能简介补充分类报表支持账户、记账归属用户组合筛选。

## 用户筛选补充

### 实现与语义

- 在账户旁增加可清空的“全部用户”选择器，仅在报表根层显示，用户名称优先显示昵称。现按后续要求复用 `familyMembers`，仅列出非管理员成员；普通成员也可使用，不请求管理员专用接口。
- 按流水的 `owner`（记账归属）筛选，不按 `created_by`（录入人）或账户的归属用户筛选。成员名单只提供当前家庭有效用户，历史已删除用户的流水仍计入“全部用户”。
- 月份、账户继续通过原流水接口筛选。已加载流水保存在源数据中，派生的流水视图按用户过滤；总额、环形图、大小类、二级分类和明细共用该视图。切换用户不重新请求接口，不改后端或 API 类型。
- 用户选择变化重置下钻，但不清空账户；月份、收支类型及账户变化保留用户。后台数据刷新后重新应用用户筛选；清空用户恢复当前月份、账户下的全部用户。
- 账户和用户置于不换行的筛选组，手机下各占一半宽度；原月份控件禁止文字输入的修复保持不变。
