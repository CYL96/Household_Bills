# 任务与需求记录目录

## 背景与目标

逐次把任务变更写入根目录 README 会使项目入口不断膨胀。将任务与需求记录独立存放，README 专注于项目说明与使用指南。

## 实际变更

- 新增 `docs/changes/`，按任务或需求创建独立 Markdown 文件。
- 在目录说明中约定文件命名、记录内容及同一任务的更新方式。
- 在 `AGENTS.md` 中加入文档维护约束。
- 根目录 README 仅增加固定文档入口；现有使用说明保留，不追溯编造历史任务或日期。

## 兼容性

仅调整文档组织方式，不修改程序、接口或数据库，无需迁移。

- 已运行文档检查脚本：4 个相关 Markdown 文件均可读取，2 个本地 Markdown 链接均可解析到实际文件，记录文件名符合命名约定。
