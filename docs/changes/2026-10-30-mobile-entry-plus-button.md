# 手机端记账入口改为加号按钮

## 背景与目标

手机端总览和流水页的「记一笔」浮动入口改为「+」号按钮，保留原有记账操作及桌面端文字按钮。

## 实际变更

- 在现有不超过 760px 的响应式样式中，将两个页面共用的浮动入口设为 48×48px 圆形按钮，隐藏文字，仅显示 22px 加号图标。
- 沿用原有右下角定位、底部导航避让和点击处理，不改记账逻辑或空状态入口。
- 两处按钮补充 `aria-label="记一笔"` 和 `title="记一笔"`，图标模式仍有明确的可访问名称。
- 更新 README 中对应的手机端使用说明。

## 验证与结果

- `frontend/` 执行 `npm run build`：通过类型检查与构建；Vite 仍提示部分产物超过 500kB，未为本次按钮调整改动分包。
- 使用 Chromium 加载实际构建产物，在总览和流水两个页面分别检查 320、390、760、761、1280px 宽度：不超过 760px 时按钮固定定位、尺寸为 48×48px、文字隐藏；761px 和 1280px 时恢复普通定位且文字显示。
- 两个页面分别在 390×844 视口点击浮动按钮，均确认打开「记一笔支出」全屏编辑界面；未保存测试账目。
- 截图确认手机端加号位于底部导航上方。浏览器环境缺少中文字体，截图中的中文显示为方框；中文名称和编辑界面内容通过 DOM 检查确认，未做真机字体验证。
- 本地现有服务的 HTTP 登录受安全配置限制，页面实测改用临时本地服务（仅监听回环地址，关闭安全 Cookie，保留同源校验）；未修改部署配置或管理员密码。
- 未运行后端测试：本次未修改后端、接口或数据库。

## 兼容性与部署

无数据库迁移、接口或依赖变更。重新构建并部署前端产物即可；桌面端继续显示带加号图标的「记一笔」文字按钮。
