# 支出分类统计层级切换

## 背景与目标

总览的支出分类环形图原先按交易中的分类名称平铺展示。二级分类较多时，图例需要多次翻页。增加「一级分类 / 所有分类」切换，支持查看汇总结构和原始分类明细。

## 实际变更

- 在支出分类图表标题下增加两项切换按钮，默认「所有分类」，保持原有统计展示；切换只影响当前页面图表，不修改交易、月度支出总额或其他统计。
- 「一级分类」按当前家庭分类配置，将一级分类本身及其二级分类的支出合并；当前名称精确匹配优先于历史名称与内置来源名称匹配，避免别名冲突导致错分。
- 停用分类的历史支出仍计入；已删除或无法匹配当前配置的历史名称单独保留，不猜测归属。
- 新增 `frontend/src/utils/categoryStatistics.ts`，以 BigInt 整数分汇总，结果转换为两位小数金额字符串，按金额降序排列，同额按名称稳定排序；仅在图表边界转换为数值。
- 图表数据、说明和无障碍标签随实际模式更新。分类配置尚未加载或加载失败时禁用一级分类，并显示所有分类，不把明细误标为一级汇总。
- 按钮保留选中态、禁用态和键盘焦点样式，支持换行；分类配置为响应式读取，保存设置后的分类归属变化可参与重新汇总。
- 更新根目录 README 的功能说明及历史名称统计口径。

## 验证与结果

- 在 `frontend/` 执行 `npm run build`：通过 `vue-tsc --noEmit` 与 Vite 生产构建。Vite 提示部分压缩后产物超过 500 kB；未为本需求额外调整分包。
- 使用临时 Node/Vite SSR 脚本直接运行实际导出的聚合函数，断言通过：
  - 一级本级、二级及历史／内置别名合计为「餐饮 3.42」。
  - 停用分类历史支出合计为「购物 5.00」。
  - 当前名称优先于其他分类的历史别名，正确得到「出行 2.50」。
  - 未匹配历史名称保留为独立项；汇总前后总额均为 12.17。
  - 空数据、无分类配置、大额金额精确到分、子分类移动后归属、同额稳定排序及不修改输入均通过。
- 临时验证脚本已移除，未引入前端测试框架。
- 未进行浏览器页面外观或交互验收，留给用户确认；构建和聚合验证不代表页面视觉验证。
- 未运行后端测试：此次未修改后端、接口或数据库。

## 兼容性与迁移

不更改 API、数据库结构、分类快照格式或历史交易记录，无需迁移。默认「所有分类」保留按交易原始名称分组的数据和顺序；一级汇总依据当前家庭配置，不重写历史账目。
