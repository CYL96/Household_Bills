# 分类图标扩充至 500 个

## 背景与目标

用户要求参考当前分类图标补充更多场景，目标准确 500 个。在现有 85 个精选图标的基础上新增 415 个，保留原有默认分类图标和已保存配置，不恢复无关的整包图标目录。

## 实际变更

- 仅扩充 `frontend/src/utils/categoryIcons.ts` 的具名导入与选项声明，使用已安装的 `@lucide/vue@1.65.0` 规范图标，排除别名和重复图形。
- 保留已有选项的 ID、中文标签、分组、组件、适用名称及相对顺序；在各组尾部追加新选项，新增 ID 使用 `lucide-<规范名称>`。
- 新项均使用空 `names`，不抢占内置名称匹配；默认分类仍使用原图标。13 个分组、通用标签回退和模块级映射解析机制不变。
- 新增场景覆盖食材烘焙、宝宝用品与成长、衣物数码配件、家电家具维修家政、检查护理康复、交通车型车况、人情礼品公益、学习文具考试、护肤理容饰品、影音运动兴趣、住宿露营景点、储蓄账户票据及通用提醒标记。
- 不新增依赖、外部请求或许可证来源，继续随前端打包并分组选择；不额外增加搜索、分页或其他交互。
- README 同步为 500 个图标选项。

## 验证与结果

- 修改前使用 Vite SSR 加载实际模块，保存原 85 个选项的 ID、标签、分组、适用名称和真实 SVG 输出，以及全部 90 个不同内置分类名称的默认映射作为临时基线。
- 修改后加载实际模块并逐个渲染：准确 500 个选项，ID、中文标签、组件引用、实际 SVG 图形均无重复；所有图形均有有效绘图节点，使用 24×24 画布和 `currentColor` 描边。
- 与基线逐项比较，原有选项及内置名称映射保持不变；全部选项分组有效、ID 满足后端 `[a-z0-9-]{1,64}` 约束并通过实际图标白名单。
- 用全部 500 个图标构造分类草稿，经实际 `prepareCategoryPreferences()` 验证后仍完整保留所选 ID；未知名称、原型属性名称及非法显式 ID 的回退检查通过。
- 语义审查后修正新增项中的误译和错组：煎蛋、天平、印章、领奖台、油漆刷、清洁刷、魔法棒、菱形及目标达成按实际图形命名和归组；修正后重新执行全部 SVG／基线检查及生产构建，均通过。
- `frontend/` 执行 `npm run build` 通过，包含 TypeScript 检查和 Vite 生产构建。最终入口 JS 为 1390.93 kB，gzip 422.56 kB；仍有部分 chunk 大于 500 kB 的提示，未抑制警告或更改分包策略。
- 未运行后端测试：本次未修改后端、协议或数据库。未进行浏览器页面外观和交互验收，SVG 渲染证明不代替页面视觉验收。
- 临时基线和烟测脚本在验证完成后清理，不新增测试框架。

## 兼容性

- 不修改分类名称、默认图标映射、层级、排序、启用状态或账目数据，不需要数据库迁移。
- 当前已保存的图标 ID 继续有效；新增图标可以通过原有分类编辑器选择并保存。
- 本次扩充会增加前端打包资源量；界面仍只渲染当前分组的选项，而不是一次显示全部 500 个。
