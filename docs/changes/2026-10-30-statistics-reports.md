# 统计导航与分类报表

## 背景与目标

新增“统计”一级导航，下设“报表”和“日历”。本任务先实现报表：进入时按一级分类汇总，点击有二级分类的一级项进入二级汇总；没有二级分类时直接查看明细；点击二级项查看对应明细。当前需求消息未附可读取的截图，页面沿用项目现有样式。

## 实际变更

- `frontend/src/components/AppNav.vue`：增加可折叠的“统计”分组，桌面侧栏和手机导航共用；“报表”为有效链接，“日历”显示“暂未开放”且不可点击，不实现日历功能。
- `frontend/src/router/index.ts`：增加受登录保护的 `/statistics/reports` 路由，`/statistics` 重定向到报表，按需加载报表页面。
- `frontend/src/views/ReportsView.vue`：默认显示当月支出，可选月份并切换收入、支出；提供分类金额、笔数、占比、环形图以及分类行下钻。明细留在报表内，展示日期时间、原始分类、账户、归属成员、金额和备注；支持面包屑和返回上一级。
- `frontend/src/utils/reportStatistics.ts`：使用整数分（`BigInt`）汇总月度流水，金额排序、统计与明细来自同一数据集；一级占比相对当月所选收支类型，二级占比相对当前一级分类。百分比按两位小数四舍五入，合计可能存在舍入尾差。
- 当前分类名称精确匹配优先于历史名称、默认名称；分类改名后历史流水汇入当前分类，停用分类的历史记录仍计入，无法匹配的历史分类独立显示。配置有二级分类但直接记在一级的流水单列“未细分”，避免下钻后漏算。
- 只展示所选月份有流水的分类；转账不计入收入或支出报表。没有流水的月份显示空态。
- 分类配置未成功加载或身份不一致时，不展示未经确认的分类归属；加载失败提供重试。月度请求保留序号保护，数据变更后刷新，已有钻取路径仅在对应分类仍存在时保留。

## 截图反馈：修复贴环标签遮挡

### 原因与调整

- 原生饼图避让已移动文字并重新计算引导线，额外的全局 `moveOverlap: 'shiftY'` 又移动一次文字，导致文字与引导线错位；原先按 28 / 36px 预留的行高也不足以容纳两行文字及间距。
- 移除重复的全局纵移，使用原生饼图避让；增加文字块最小间隔和引导线外伸距离，自适应高度按完整的两行文字及间距计算。
- 密集分类下，原生贴环椭圆定位可能把远离圆环上下端的标签横向推得过远。新增基于实际画布宽度的局部位置 / 文字宽度约束，仅修正这些越界位置，不恢复左右边缘对齐；位置变更后由 ECharts 同步更新引导线。
- 按视口宽度预留左右标签空间；窄屏适当缩小圆环，长名称允许截断，但保留完整百分比。分类、金额、占比口径与明细操作不变。
