# 分类子分类个数右侧显示

## 背景与目标

根据页面截图，将一级分类名称下方的“n 个子分类”移到卡片右侧、展开箭头之前显示。

## 实际变更

- 在 `frontend/src/components/CategorySettingsDialog.vue` 中，将子分类个数从名称下方移到名称区域之后、展开箭头之前。
- 个数保持次要文字样式，禁止换行和压缩；名称区域继续自适应剩余宽度，过长名称仍省略显示。
- 已停用分类仍在名称下方显示“已停用”，子分类个数同样右侧显示。
- 根据后续截图，删除展开区域内重复的“子分类 / n 个”标题行及其无用样式；数量仅在卡片右侧显示，保留子分类卡片和添加按钮。
- 根据再次标注的截图，移除正常分类列表上方的“一级分类 / 长按拖动排序”整行，不保留该行占位；已停用分组仍保留标题与恢复说明，便于区分。
- 移除展开区域顶部的虚线，将顶部内边距调整为 8px，以留白分隔分类标题和子分类卡片。
- 将整行“添加子分类”按钮改为网格末尾的加号图标卡片，复用子分类卡片尺寸及焦点、禁用样式；空分类直接显示加号入口，移除整行空态提示和旧按钮样式。
- 加号入口保留中文悬停提示及带一级分类名称的无障碍标签，不绑定拖动手势，也不带分类卡片排序标记；分类节点与添加节点使用互不冲突的键。
- 根据后续反馈，将添加入口的加号图标从 22px 缩小为 16px，保留卡片尺寸和点击范围。
- 不改变展开、更多操作及拖动排序逻辑。
